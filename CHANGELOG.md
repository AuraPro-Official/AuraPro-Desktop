## [3.9.8] - 2026-08-03

### Changed

- Updated the default AuraPro WebUI distribution to version 3.9.8.

### Fixed

- Fixed false installation-directory permission errors caused by transient antivirus or system file locks on Windows.
- Added bounded retries and more reliable cleanup to the installation write probe.
