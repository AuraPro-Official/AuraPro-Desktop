## 已修复问题

### 后续：普通 WebUI 聊天上下文精简

启用上下文精简的普通聊天现结合本轮内容长度估算与上一轮真实用量触发精简，避免无用量模型和新增长输入漏过阈值。估算不显示为真实消耗。长历史分批生成摘要并传递上一批摘要；空摘要不再用前 500 字拼接替代。精简失败保留聊天历史并报错，不继续发送可能超限的完整历史。翻译/同传等原有硬截断模式未变，用户关闭精简时也保留其偏好。25 项上下文回归通过，模型摘要使用固定测试响应，未验证每个模型的摘要质量。

### 后续：执行中上下文精简与续跑

显式开启 PI 自动上下文精简，按 WebUI 所选模型窗口调整摘要预算和最近历史保留量；转发压缩开始/结束事件到 WebUI 状态及上下文圆环。可恢复模型错误不再提前终止任务，等 PI 完全 settled 后才判定失败。任务授权保持到完全 settled，压缩期间不重置。实际 PI 的固定模型测试主动返回上下文超限：确认发起摘要、收到压缩事件、恢复调用并完成任务；15 项 PI RPC、16 项后端辅助测试通过。模型单次输出长度限制仍存在，不等同于上下文精简。

### 后续：Agent token 用量

PI 消息转换保留模型 usage，模型通道请求流式用量。每次模型调用完成后，当前任务累计输入、输出和缓存 token 用量发送到 WebUI 并保存；输入框上下文圆环使用最近一次调用的用量与 PI 实际上下文窗口，避免把多轮消耗累计当作上下文占用。无模型用量时不生成估计数字。实际 PI 测试验证两次调用的输入/输出用量均保留；16 项后端辅助测试、14 项 PI RPC 测试和模型通道测试通过。

### 后续：输入框 Agent 控件与完全控制

开启 Agent 模式后，输入框左下角显示工作文件夹与审批规则。原生文件夹选择与三种审批规则切换通过真实 Svelte 组件的 Chrome 测试（目录验证 API 和原生选择器使用固定测试响应）。完全控制跳过本轮授权与工具确认，并自动通过扩展 confirm；select/input/editor 仍等待用户提供信息。工作区边界和计划模式仍有效。14 项实际 PI RPC 测试、15 项后端回归、完全控制策略检查及 WebUI 构建通过，已同步安装版。

### 后续：当前任务授权与自动审批

WebUI 的 PI 菜单新增“审批方式”：默认“任务内自动审批（推荐）”，可切换“每步确认”。任务模式开始时确认一次，授权只在本轮有效，结束立即清除。观察与读取不反复确认；已观察到的普通文件夹点击、右键和允许的导航动作可连续执行。删除、发送、提交、写文件、脚本及无法识别的操作仍单独确认。允许列表是保守规则，不能保证识别所有界面风险。

真实 PI RPC 回归 13 项通过，包括本轮任务授权与文件写入分别确认；审批策略测试验证两次普通右键仅一次任务授权、发送操作单独确认、任务结束后动作被阻止、新任务重新授权。WebUI 生产构建通过，桥接、后端及静态文件已同步安装版并重启，健康检查通过。新增选择器没有重新进行登录页面端到端测试：复查时原临时 API Key 已返回 401。此变更不解决下述资源管理器前台焦点问题。

### 后续：电脑任务错误使用 PowerShell

截图任务“打开 D 盘后右键”实际使用了 powershell。桥接层现为电脑任务启用电脑工具并禁用 powershell，补充正确 stateId、键盘定位、菜单观察规则。观察工具不反复弹授权，动作仍需确认；Windows 原生新菜单引用与扩展引用冲突时，动作后提供新窗口清单。

真实 low_E4 复测确认使用 find_roots/observe_ui/act_ui 而非 powershell，并可识别 D 盘资源管理器。但物理右键仍遇到 Windows refused to foreground the target，未发送输入，不能算该场景通过。已增加明确中文通知；原独立 Windows Forms 测试覆盖 UIA 输入/按钮，不能推导资源管理器右键已可用。前台窗口授权/焦点切换仍需进一步修复。

### 后续：长代码生成被截断却显示完成

实际失败会话中两次 write 被截断，最后一次输出仅 1 token。现保留 PI 的 stopReason，最终截断或工具失败未恢复时显示“PI 任务未完成”，不再填充“PI completed the task”。异常退出也会覆盖成功阶段状态。

代码任务按需加载扩展工具，避免常驻浏览器与电脑工具说明挤占上下文；新增工具可在执行中启用所需扩展。生成大文件时提示分段写入，并要求完成实现与检查，避免只写骨架就询问是否继续。

真实 low_E4 生成约 17 KB 俄罗斯方块 HTML，Chrome 验证页面加载、启动、方向键/旋转/落下操作无 JavaScript 错误。强制 max_tokens=1 的实际聊天测试正确返回 failed 和“未完成”。本次 PI RPC 12 项、兼容/失败判断 15 项测试通过。

- 用户主目录快照扫描耗时过长，导致任务超过 35 秒且错误内容为空。快照扫描现有 3 秒和 10,000 文件上限，排除 AppData 等依赖/缓存目录；不完整扫描不误报文件被删除。
- PI 需要独立模型设置。模型由 WebUI 选定，通过临时本地通道传给 PI；已移除 PI 独立模型设置面板。
- 启动扩展时等待确认阻塞任务提交。提交异步执行，确认事件可及时消费。
- 输入事件断线错误被当作用户输入。错误回传取消请求。
- 多行编辑 Enter 提前提交；中文输入法组合输入可能触发确认。多行编辑 Enter 换行，Ctrl/Command+Enter 确认，组合输入不提交。
- 差异没有独立原/新行号；以 ---/+++ 开头的修改内容被误认文件头；无末尾换行的修改合并显示。已修复。
- 取消恢复弹框导致加载状态卡住。取消不再设置加载状态。
- 普通文件任务会自动连接浏览器并弹连接失败。改为实际使用浏览器工具时连接。
- 扩展命令抛错时缺少可见提示。桥接层转成 WebUI 错误通知。
