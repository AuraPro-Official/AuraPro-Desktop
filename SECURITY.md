# Security Policy

## Supported Versions

Security fixes are provided for the latest production release. Users should
upgrade to the most recent available version before requesting support for a
security issue in an older release.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in public issues, discussions, pull
requests, or social channels.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/AuraPro-Official/AuraPro-Desktop/security/advisories/new

Include:

- A description of the issue and its potential impact.
- Affected versions and operating systems.
- Reproduction steps or a minimal proof of concept.
- Relevant logs with credentials and personal data removed.
- Any known mitigations.

The maintainers will review the report, assess severity, coordinate a fix, and
publish an advisory when appropriate. Please allow time for investigation and
release preparation before public disclosure.

## Scope

Security reports may cover the desktop client, installers, update process,
local runtime management, privileged filesystem operations, authentication
boundaries, and handling of sensitive local data.

Vulnerabilities in third-party services or dependencies should also be reported
to the responsible upstream project when appropriate.
