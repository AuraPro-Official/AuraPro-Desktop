# Support

## Product Support

Use the repository's issue forms for reproducible defects and feature requests:

https://github.com/AuraPro-Official/AuraPro-Desktop/issues/new/choose

Before submitting a report:

- Update to the latest supported release.
- Review the documentation and existing issues.
- Remove passwords, tokens, private documents, and personal data from logs.
- Record the AuraPro version, operating system, architecture, and reproduction
  steps.

## Security Issues

Security vulnerabilities must not be reported publicly. Follow
[SECURITY.md](SECURITY.md) for private reporting instructions.

## Third-Party Components

Issues caused exclusively by external model providers, operating system
policies, GPU drivers, or other third-party services may need to be reported to
the relevant vendor. AuraPro diagnostics and logs can help identify the
responsible component.
